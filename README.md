# Najot Ta'lim course work

Homework and exam projects from my Python backend course at Najot Ta'lim (March–July 2026), covering Django, Django REST Framework and FastAPI. Each folder was originally a separate repository; its commit history is preserved here.

| Folder | Topic | Period | What's inside |
|---|---|---|---|
| [django-lessons](django-lessons) | Django | Mar–Apr 2026 | 8 projects: models and the ORM, function-based and class-based views, ModelForms, templates, a custom user model, and the exam project (`Imtihon`) |
| [watchshop_project](watchshop_project) | Django | Apr 2026 | LuxWatch: a watch marketplace with user listings, search and filters |
| [drf-lessons](drf-lessons) | Django REST Framework | Apr–Jun 2026 | 12 projects: `@api_view` → `APIView` → generic views → ViewSets and routers, token and JWT auth, permissions, OpenAPI docs, and the exam project (`rest11`, an e-commerce API) |
| [fastapi-nt](fastapi-nt) | FastAPI | Jun–Jul 2026 | Homeworks `hw02`–`hw07` and `fastapi_async`: SQLAlchemy (sync and async), Alembic, JWT, pytest, Redis. `hw08`–`hw09`: Celery with Redis, and RabbitMQ messaging (Django) |

Every project runs on its own. `django-lessons`, `drf-lessons` and `watchshop_project` have READMEs with setup steps; in `fastapi-nt` each homework folder is a standalone app.
